# Skill: Billing Review

Purpose: inspect IBSng E balance and billing state before taking any financial or account action.

Workflow:
1. Identify the user or customer unambiguously.
2. Inspect balances using the generated balance tools.
3. Inspect invoice/payment records relevant to the request.
4. Check dates, currency/value type and lifecycle state before interpreting amounts.
5. Distinguish balance configuration from the customer's actual financial state.
6. Present observed values and inferred conclusions separately.
7. Do not add credit, delete balances, change billing data or otherwise mutate financial state without explicit authorization.
